# Release Notes

## Version: 0.1.0

### Initial Release

- Per-slot item level overlays on all equipment slots (Character and Inspect frames)
- Enchant name display on enchanted slots; red-dot warning on missing enchants
- Gem count display (filled/total) on socketed slots; orange highlight for empty sockets
- Specialisation badge (icon + name + role) on the Character frame
- Role icon beside the spec line on the Inspect frame
- Secondary stats panel (Crit / Haste / Mastery / Versatility / Speed / Leech / Avoidance) below the Character frame stat pane
- Inspect request queue with server-throttle protection (1.2 s cooldown, 4 s timeout, 1 retry)
- Blizzard Interface Options panel with per-feature toggles
- `/dcf` slash command to open settings
